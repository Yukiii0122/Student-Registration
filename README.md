Student-Registration

Description:
The Student Registration System is a simple Python-based application designed to manage student registration. It allows users to register students, view registered student information, and validate input.

Purpose:
The purpose of this system is to make student registration more organized, efficient, and easier to manage.

Features:
Register new students
View registered students
Validate required fields
Prevent duplicate student IDs
Simple menu-driven interface

Technologies Used:
Python
Git
GitHub

How to Run:
Install Python.
Download or clone this repository.
Open a terminal in the project folder.
Run python main.py.
